## 3. Operational Measurement Notes

- **Auditing Window:** Metrics and system telemetry performance profiles were captured on-chain during the formal Milestone 3 evaluation sequence on **May 30, 2026**.
- **SDK Protocol Alignment:** Core transaction assembly routines and spending validator integrations were re-verified after locking the environment dependencies down to Mesh SDK version `@meshsdk/core@1.9.0-beta.104`.
- **Pipeline Completeness:** The execution trail processed linearly (`Create (Ha Noi) → Update (Ha Noi -> China) → Update (China -> American) → Burn`) across the decentralized Preprod ledger architecture without experiencing orphaned blocks or UTxO spend rejections.
- **Data Integrity Verification:** On-chain storage structures mirror the CIP-68 standard layout. Asset reference parameters partition data handling via `User Token (Label 222)` codes and `Reference Token (Label 100)` metadata datums, verified across both Blockfrost data pipelines and CExplorer indexers (`8c03ad9c...`, `62ad9ccb...`, `044d57b4...`, `9093e0b4...`).
- **Network Dependency Factors:** Recorded block settlement durations remain linked to active Cardano testnet slot performance limits. The observed baseline of 43.4 seconds reflects standard BFT/Praos consensus execution parameters under normal network loads.
- **Client Resilience Optimization:** The interactive mobile web dashboard handles network-to-indexer sync delays gracefully by utilizing a custom post-decode synchronous validation state machine inside `ProductScanner.tsx`, preventing operators from seeing stale edge-cached states.
