# Testing Log — QR Code Supply Chain

**Status:** Fully verified on Cardano Preprod as of May 30, 2026. The complete product traceability lifecycle has been successfully executed and validated on-chain, including: `Create → Update → Query Tracking → Update → Query Tracking → Burn`. A total of four Cardano transactions were submitted and confirmed during the validation process.

This testing log serves as a retrospective record of the completed implementation. The QR Code Supply Chain prototype was developed and functionally validated during Phase 2, while the test cases documented below were re-executed on the finalized prototype and formally recorded in Phase 3.

## 4. Notes

- All 7 test cases passed successfully during Milestone 3 re-validation on 2026-05-30.
- The complete product lifecycle (Create → Update → Update → Burn) was executed with a total of 4 confirmed Cardano Preprod transactions.
- Product metadata was managed using the CIP-68 standard (Label 721 for JSON metadata, Label 333 for asset references).
- Transaction confirmation times depend on Cardano Preprod network conditions and Blockfrost API latency; observed average was 43.4 s for the initial mint.
- QR code validation workflow ensures that scanned product data matches the on-chain record before displaying product history to the user.
- All deviations from Milestone 2 demo behavior are documented in [`issue-resolution.md`](./issue-resolution.md) with corresponding fixes and verification evidence.
